# Internationalization (i18n)

The app ships in three languages:

| Code | Language |
|---|---|
| `en` | English |
| `fr` | Français |
| `rw` | Kinyarwanda |

`en` is the **source of truth**. `fr` and `rw` mirror its key structure.

## How it's wired

- Setup lives in [`src/lib/i18n/index.ts`](../src/lib/i18n/index.ts) using
  `i18next` + `react-i18next` + the browser language detector.
- Each language is a plain object exported from `en.ts`, `fr.ts`, and `rw.ts` in
  the same folder.
- Language is detected from `localStorage` first, then the browser's
  `navigator` language, and cached back to `localStorage`.
- `fallbackLng` is `en` — a missing key falls back to English.

## Using translations in components

```tsx
import { useTranslation } from 'react-i18next';

function Example() {
  const { t } = useTranslation();
  return <h1>{t('dashboard.welcome')}</h1>;
}
```

Rules:

- **Never hardcode user-facing text.** Always go through `t('...')`.
- Use existing namespaced keys where they fit; group new keys logically.

## Adding or changing a string

1. **Add to `en.ts` first** — this defines the key and the canonical English
   text.
2. **Add the same key to `fr.ts` and `rw.ts`.** Keys must exist in all three
   files so nothing falls back silently to English in production.
3. For a language you are **not fluent in**, provide a best-effort value and
   flag it for native-speaker review rather than leaving it out:

   ```ts
   // rw.ts
   someKey: 'Best-effort Kinyarwanda string [REVIEW RW]',
   ```

   The `[REVIEW RW]` marker makes pending translations easy to grep and lets a
   native speaker confirm them before release. Use the equivalent marker
   (e.g. `[REVIEW FR]`) for French when needed.

4. Switch languages in the UI (via the `LanguageSwitcher`) and verify the new
   string renders in each language.

## Switching language in the UI

The `LanguageSwitcher` component
([`src/components/shared/LanguageSwitcher.tsx`](../src/components/shared/LanguageSwitcher.tsx))
lets users change language; the choice persists in `localStorage`. Supported
languages are listed in `SUPPORTED_LANGUAGES` in `src/lib/i18n/index.ts`.

## Checklist for translation PRs

- [ ] Key added to `en.ts`, `fr.ts`, and `rw.ts`.
- [ ] Any uncertain translation is marked with a `[REVIEW XX]` flag.
- [ ] No hardcoded display strings introduced.
- [ ] Verified in the browser across languages.
